# Simutrans Timetables

A catalogue of every timetable and fleet sheet built for a Simutrans 122.0 fork that models real Czech public transport (city
trams, trolleybuses and buses, ODIS regional buses, rail), plus the knowledge base of rules behind them.

Each sheet converts the real timetable and vehicle allocation into the values typed into the game (*Departure every / Offset /
Also at* per Simutrans line and terminus, and the actual vehicles by fleet number with their pak128 object). The web app shows
every sheet in its original design, alongside:

- **sources** — which feeds and registers it was built from;
- **sync** — which pipeline rebuilds it, the command, and the update recipe;
- **dates** — the data day (vehicles / network), when it was created, when it was last published, when it was synced here.

## Contents
| Path | What |
|---|---|
| `app/`, `lib/` | Next.js App Router site (all pages prerendered) |
| `public/sheets/` | the sheets as built, served untouched |
| `data/catalog.json` | hand-written metadata per sheet |
| `data/provenance.json` | publish history mined from Claude Code transcripts |
| `data/sheets.json` | generated by `pnpm sync` |
| `mirror/pipeline/` | the pipeline code and docs (no data) copied from the working folder |
| `kb/` | rules, data sources, workflow, lessons, related projects, original notes |
| `tools/` | `sync.mjs`, `mine_transcripts.py` |

## Use
```sh
pnpm install
pnpm dev          # http://localhost:3000
pnpm sync         # pull sheets + pipeline code from the working folder (SIMUTRANS_SOURCE=…)
pnpm provenance   # refresh publish history from local transcripts
pnpm build
```

The pipelines themselves run in the working folder, which holds ~1.1 GB of raw downloads that are deliberately not in this repo.
Start with [`kb/README.md`](kb/README.md) and [`CLAUDE.md`](CLAUDE.md).
